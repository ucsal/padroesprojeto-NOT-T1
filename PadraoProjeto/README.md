## Interpreter

O padrão Interpreter permite interpretar expressões de uma linguagem simples, representando suas regras em classes. Cada classe sabe interpretar uma parte da expressão, e a combinação dessas partes permite avaliar expressões mais complexas, como cálculos matemáticos ou condições de um filtro. O que permite que você crie implementações compostas como em algum caso (Como o exemplo da soma).
