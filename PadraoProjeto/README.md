## Command

O padrão Command transforma uma ação em um objeto. Esse objeto reúne o necessário para executar uma tarefa, permitindo separar quem solicita a ação de quem a realiza. Ou seja, num exemplo onde a gente trabalha com uma interface, o objeto não precisar saber qual comando ele está executando, somente saber que ele é um gatilho, o que permite que o command seja substituído por outro facilmente.
